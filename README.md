Freedom Basic

Ένας interpreter/IDE συμβατός με Liberty BASIC 4.5.1, για Windows (32-bit και 64-bit). A Liberty BASIC 4.5.1 compatible interpreter and IDE for Windows (32-bit and 64-bit).

Λήψη / Download

Πάρε το τελευταίο exe από τα Releases: FreedomBasic64bit.exe για 64-bit Windows (οι περισσότεροι υπολογιστές) ή FreedomBasic32bit.exe για 32-bit. Δεν χρειάζεται εγκατάσταση: κατεβάζεις και τρέχεις.

Shareware
30 ημέρες δωρεάν δοκιμή με πλήρη λειτουργία.
Μετά τη λήξη, το πρόγραμμα ανοίγει μόνο για ανάγνωση (χωρίς Run, Compile, Save).
Για πλήρη λειτουργία: Tools → Activate…, δώσε τον κωδικό υπολογιστή που εμφανίζεται στον προμηθευτή και γράψε το κλειδί που θα πάρεις. Διαθέσιμες άδειες: 2 έτη ή εφόρου ζωής.
Το κλειδί ισχύει μόνο για τον υπολογιστή που το ζήτησε.
