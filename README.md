# Freedom Basic

Ένας interpreter/IDE συμβατός με Liberty BASIC 4.5.1, για Windows (64-bit).
A Liberty BASIC 4.5.1 compatible interpreter and IDE for Windows (64-bit).

## Λήψη / Download
Πάρε το τελευταίο `FreedomBasic.exe` από τα **[Releases](../../releases/latest)**.
Δεν χρειάζεται εγκατάσταση: κατεβάζεις και τρέχεις.

## Shareware
- **30 ημέρες δωρεάν δοκιμή** με πλήρη λειτουργία.
- Μετά τη λήξη, το πρόγραμμα ανοίγει **μόνο για ανάγνωση** (χωρίς Run, Compile, Save).
- Για πλήρη λειτουργία: Tools → Activate…, δώσε τον κωδικό υπολογιστή που εμφανίζεται
  στον προμηθευτή και γράψε το κλειδί που θα πάρεις. Διαθέσιμες άδειες: **2 έτη** ή **εφόρου ζωής**.
- Το κλειδί ισχύει μόνο για τον υπολογιστή που το ζήτησε.
