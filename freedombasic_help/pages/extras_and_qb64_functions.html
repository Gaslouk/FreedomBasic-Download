Extras and QB64 functions

_BIN$ / HEX$ / OCT$

_BIN$(n) / HEX$(n) / OCT$(n)

Return n as binary, hexadecimal or octal text.

Επιστρέφουν το n ως δυαδικό, δεκαεξαδικό ή οκταδικό κείμενο.

print _bin$(5)
print hex$(255)
print oct$(8)
101
FF
10

_DELAY / _LIMIT / _TITLE

_DELAY seconds / _LIMIT fps / _TITLE "text"

_DELAY pauses; _LIMIT caps a loop at a number of passes per second; _TITLE sets the window title.

Το _DELAY κάνει παύση· το _LIMIT περιορίζει έναν βρόχο σε επαναλήψεις ανά δευτερόλεπτο· το _TITLE ορίζει τον τίτλο του παραθύρου.

_title "Demo"
_delay 0.01
_limit 100
print "ok"
ok

_NEWIMAGE / SCREEN

s = _NEWIMAGE(w, h, 32) : SCREEN s

Creates a drawing surface and makes it the screen. After SCREEN, PRINT writes on the graphics screen, not the text window.

Δημιουργεί επιφάνεια σχεδίασης και την κάνει οθόνη. Μετά το SCREEN το PRINT γράφει στην οθόνη γραφικών, όχι στο παράθυρο κειμένου.

s = _newimage(200, 100, 32)
screen s
print "hello"

Not run in the automatic check: after SCREEN the text goes to the graphics window, which the automatic check cannot capture

_RED32 / _GREEN32 / _BLUE32

_RED32(c) / _GREEN32(c) / _BLUE32(c)

Extract one colour component from a packed colour.

Εξάγουν ένα συστατικό χρώματος από πακεταρισμένο χρώμα.

c = _rgb(1, 2, 3)
print _red32(c); _green32(c); _blue32(c)
123

_RGB / _RGBA

_RGB(r, g, b) / _RGBA(r, g, b, a)

Pack a colour into one number. _RGB(r,g,b) equals r*65536 + g*256 + b. _RGBA adds the alpha (transparency) value.

Συμπιέζουν ένα χρώμα σε έναν αριθμό. Το _RGB(r,g,b) ισούται με r*65536 + g*256 + b. Το _RGBA προσθέτει την τιμή alpha (διαφάνεια).

print _rgb(255, 0, 0)
print _rgb(1, 2, 3)
16711680
66051

_SHL / _SHR / _ROL / _ROR

_SHL(n, k) / _SHR(n, k) / _ROL(n, k) / _ROR(n, k)

Shift or rotate the bits of a number left or right by k places.

Ολισθαίνουν ή περιστρέφουν τα bits ενός αριθμού αριστερά ή δεξιά κατά k θέσεις.

print _shl(1, 3)
print _shr(8, 2)
8
2

CALLDLL

CALLDLL #lib, "function", arg AS type, result AS type

Calls a function of a Windows DLL. Only meaningful in the Windows build.

Καλεί συνάρτηση από Windows DLL. Έχει νόημα μόνο στο Windows build.

calldll #kernel32, "GetTickCount", r as long
print r > 0

Not run in the automatic check: works only in the Windows build

CHDIR / DIR$ / DEFAULTDIR$ / STARTUPDIR$

CHDIR "folder" / DIR$() / DEFAULTDIR$ / STARTUPDIR$

CHDIR changes the current folder. DIR$() returns the current folder, DEFAULTDIR$ the default one and STARTUPDIR$ the folder the program started from.

Το CHDIR αλλάζει τον τρέχοντα φάκελο. Το DIR$() επιστρέφει τον τρέχοντα φάκελο, το DEFAULTDIR$ τον προεπιλεγμένο και το STARTUPDIR$ τον φάκελο εκκίνησης.

chdir "."
print len(dir$()) > 0
print len(defaultdir$) > 0
print len(startupdir$) > 0
1
1
1

COLORDIALOG

COLORDIALOG "default", result$

Shows a colour picker. result$ receives the chosen colour.

Εμφανίζει επιλογέα χρώματος. Το result$ παίρνει το χρώμα που επιλέχθηκε.

colordialog "red", c$
print c$

Not run in the automatic check: opens a dialog box

DEFINT / DEFSTR / DEFDBL

DEFINT letter-range / DEFSTR letter-range / DEFDBL letter-range

Accepted for QB64 programs. Variables keep working as before: Freedom stores numbers as double precision and strings by the $ suffix.

Γίνονται δεκτά για προγράμματα QB64. Οι μεταβλητές δουλεύουν όπως πριν: το Freedom κρατά τους αριθμούς σε διπλή ακρίβεια και τα κείμενα με την κατάληξη $.

defint a-z
a = 3
print a
defdbl d
d = 1 / 3
print d
3
0.33333333

DISPLAYWIDTH / DISPLAYHEIGHT

DISPLAYWIDTH / DISPLAYHEIGHT

Size of the screen in pixels.

Μέγεθος της οθόνης σε pixels.

print displaywidth > 0
print displayheight > 0
1
1

LPRINT

LPRINT expression

Sends text to the default printer.

Στέλνει κείμενο στον προεπιλεγμένο εκτυπωτή.

lprint "Hello printer"

Not run in the automatic check: sends text to the printer

MOUSEX / MOUSEY

MOUSEX / MOUSEY

Mouse position inside the active window.

Θέση του ποντικιού μέσα στο ενεργό παράθυρο.

print mousex; mousey

Not run in the automatic check: the position depends on the mouse

PEEK / POKE

POKE address, value / PEEK(address)

Stores and reads a byte in a small memory area of the program.

Αποθηκεύει και διαβάζει ένα byte σε μια μικρή περιοχή μνήμης του προγράμματος.

poke 100, 5
print peek(100)
5

PLAYMIDI / STOPMIDI

PLAYMIDI "file.mid" / STOPMIDI

Plays a MIDI music file in the background; STOPMIDI stops it.

Παίζει αρχείο μουσικής MIDI στο παρασκήνιο· το STOPMIDI το σταματά.

playmidi "song.mid"
stopmidi
print "called"

Not run in the automatic check: needs a MIDI file and sound output

SHELL / RUN

SHELL "command" / RUN "program"

Runs an operating system command or another program.

Εκτελεί εντολή του λειτουργικού ή άλλο πρόγραμμα.

shell "echo hi"
print "back"

Not run in the automatic check: output depends on the operating system

SLEEP

SLEEP seconds

Pauses the program for the given number of seconds.

Σταματά το πρόγραμμα για τα δοσμένα δευτερόλεπτα.

sleep 1
print "awake"
awake

VERSION$ / COMMAND$

VERSION$ / COMMAND$

VERSION$ returns the Liberty BASIC version being imitated. COMMAND$ returns the command line given to the program.

Το VERSION$ επιστρέφει την έκδοση του Liberty BASIC που μιμείται. Το COMMAND$ επιστρέφει τη γραμμή εντολών του προγράμματος.

print version$
print len(command$)
4.5.1
0

WINDOW (QB64 form)

WINDOW (x1, y1)-(x2, y2)

Sets your own coordinate system for the QB64 graphics screen (after SCREEN or _NEWIMAGE).

Ορίζει δικό σου σύστημα συντεταγμένων για την οθόνη γραφικών της QB64 (μετά από SCREEN ή _NEWIMAGE).

screen 12
window (0, 0)-(100, 100)
pset (50, 50)

Not run in the automatic check: it changes the coordinates of the graphics screen, so the text output cannot be captured by the automatic check
