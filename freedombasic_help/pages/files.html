BINARY files (PUT / GET)

OPEN "file" FOR BINARY AS #n : PUT #n, position, a$ : GET #n, position, a$

A binary file is read and written byte by byte. PUT writes a variable at a position, SEEK moves, INPUT$ reads bytes back.

Ένα binary αρχείο διαβάζεται και γράφεται byte προς byte. Το PUT γράφει μια μεταβλητή σε μια θέση, το SEEK μετακινεί, το INPUT$ διαβάζει bytes.

open "b.bin" for binary as #1
a$ = "ABCD"
put #1, 1, a$
seek #1, 2
print input$(#1, 2)
close #1
CD

BMPSAVE / LOADBMP / UNLOADBMP

BMPSAVE "name","file.bmp" / LOADBMP "name","file.bmp" / UNLOADBMP "name"

BMPSAVE saves an image held under a name to a .bmp file; LOADBMP loads a file under a name; UNLOADBMP frees it.

Το BMPSAVE αποθηκεύει μια εικόνα που έχει όνομα σε αρχείο .bmp· το LOADBMP φορτώνει αρχείο με όνομα· το UNLOADBMP την ελευθερώνει.

nomainwin
open "g" for graphics as #g
print #g, "fill red"
print #g, "getbmp a 0 0 10 10"
bmpsave "a", "red.bmp"
loadbmp "b", "red.bmp"
unloadbmp "b"
print "saved"
saved

CLOSE

CLOSE #n

Closes the file with handle #n and writes any pending data. Always close a file before reopening it.

Κλείνει το αρχείο με αριθμό #n και γράφει ό,τι εκκρεμεί. Κλείνε πάντα ένα αρχείο πριν το ξανανοίξεις.

open "c.txt" for output as #1
print #1, "data"
close #1
print "closed"
closed

EOF

EOF(#n)

Returns 1 when the end of the file has been reached, otherwise 0. Use it to control a reading loop.

Επιστρέφει 1 όταν έχει φτάσει το τέλος του αρχείου, αλλιώς 0. Χρησιμοποίησέ το για να ελέγχεις βρόχο ανάγνωσης.

open "e.txt" for output as #1
print #1, 1
print #1, 2
print #1, 3
close #1
open "e.txt" for input as #1
while eof(#1) = 0
    input #1, a
    total = total + a
wend
close #1
print total
6

FILES

FILES path$, spec$, info$(

Lists the files that match spec$ in the folder path$. The array info$( is filled: info$(0,0) holds the number of files found and info$(1,0), info$(2,0)... hold their names. Note the open parenthesis after the array name.

Παραθέτει τα αρχεία του φακέλου path$ που ταιριάζουν στο spec$. Ο πίνακας info$( γεμίζει: το info$(0,0) έχει τον αριθμό των αρχείων και τα info$(1,0), info$(2,0)... τα ονόματα. Πρόσεξε την ανοιχτή παρένθεση μετά το όνομα του πίνακα.

open "fa.txt" for output as #1
close #1
open "fb.txt" for output as #1
close #1
files ".", "f?.txt", i$(
print val(i$(0, 0))
for k = 1 to val(i$(0, 0))
    print i$(k, 0)
next k
2

fb.txt

INPUT #

INPUT #n, var1[, var2 ...]

Reads comma-separated values from a file into variables. Numeric variables read numbers, string variables read text (quotes optional).

Διαβάζει από αρχείο τιμές χωρισμένες με κόμμα και τις βάζει σε μεταβλητές. Οι αριθμητικές μεταβλητές διαβάζουν αριθμούς, οι αλφαριθμητικές κείμενο (τα εισαγωγικά είναι προαιρετικά).

open "i.txt" for output as #1
print #1, "7,apple,2.5"
close #1
open "i.txt" for input as #1
input #1, n, f$, x
print n; " "; f$; " "; x
close #1
7 apple 2.5

Διαβάζει ακριβώς count χαρακτήρες από ανοιχτό αρχείο και τους επιστρέφει ως κείμενο.

open "s.txt" for output as #1
print #1, "abcdefgh";
close #1
open "s.txt" for input as #1
print input$(#1, 3)
close #1
abc

LOF

LOF(#n)

Returns the length of the open file in bytes. A line written with PRINT # includes its line break in the count.

Επιστρέφει το μήκος του ανοιχτού αρχείου σε bytes. Μια γραμμή που γράφτηκε με PRINT # περιλαμβάνει στο μήκος και την αλλαγή γραμμής.

open "len.txt" for output as #1
print #1, "12345";
close #1
open "len.txt" for input as #1
print lof(#1)
close #1
5

OPEN

OPEN "file" FOR INPUT|OUTPUT|APPEND|BINARY|RANDOM AS #n

Opens a file and gives it a handle #n (1, 2, 3...). OUTPUT creates or empties the file, APPEND adds at the end, INPUT reads. Opening a missing file for INPUT stops the program with the error "Cannot open file". Use FREEFILE to get an unused number.

Ανοίγει ένα αρχείο και του δίνει αριθμό #n (1, 2, 3...). Το OUTPUT δημιουργεί ή αδειάζει το αρχείο, το APPEND προσθέτει στο τέλος, το INPUT διαβάζει. Αν το αρχείο δεν υπάρχει και το ανοίξεις για INPUT, το πρόγραμμα σταματά με το σφάλμα "Cannot open file". Το FREEFILE δίνει ελεύθερο αριθμό.

open "demo.txt" for output as #1
print #1, "first"
close #1
open "demo.txt" for append as #1
print #1, "second"
close #1
open "demo.txt" for input as #1
while eof(#1) = 0
    line input #1, l$
    print l$
wend
close #1
first
second

PRINT #

PRINT #n, expression[;|,expression...]

Writes text to an open file followed by a line break. A trailing semicolon suppresses the line break, so the next PRINT # continues on the same line.

Γράφει κείμενο σε ανοιχτό αρχείο και αλλαγή γραμμής. Ένα ερωτηματικό στο τέλος καταργεί την αλλαγή γραμμής, ώστε το επόμενο PRINT # να συνεχίσει στην ίδια γραμμή.

open "p.txt" for output as #1
print #1, "a";
print #1, "b"
print #1, 42
close #1
open "p.txt" for input as #1
line input #1, x$
print x$
line input #1, y$
print y$
close #1
ab
42

Random-access files (FIELD, LSET, RSET, GET, PUT)

OPEN "f" FOR RANDOM AS #n LEN = size : FIELD #n, w AS a$, w2 AS b$ : LSET a$ = x$ : PUT #n, rec : GET #n, rec

A random-access file is a table of fixed-size records. FIELD names the pieces of a record. LSET (or RSET) puts text into a field, left (or right) aligned. PUT #n, rec writes the record number rec; GET #n, rec reads it. Without a record number the next record is used. LOF(#n) gives the file size in bytes.

Ένα αρχείο τυχαίας πρόσβασης είναι πίνακας από εγγραφές σταθερού μεγέθους. Το FIELD ονομάζει τα κομμάτια μιας εγγραφής. Το LSET (ή RSET) βάζει κείμενο σε πεδίο, με στοίχιση αριστερά (ή δεξιά). Το PUT #n, rec γράφει την εγγραφή rec· το GET #n, rec τη διαβάζει. Χωρίς αριθμό εγγραφής χρησιμοποιείται η επόμενη. Το LOF(#n) δίνει το μέγεθος του αρχείου σε bytes.

open "rr.dat" for random as #1 len=10
field #1, 4 as a$, 6 as b$
lset a$ = "ab"
lset b$ = "cdef"
put #1, 1
lset a$ = "xy"
lset b$ = "zz"
put #1, 3
get #1, 1
print trim$(a$); "|"; trim$(b$)
get #1, 3
print trim$(a$); "|"; trim$(b$)
print lof(#1)
close #1
ab|cdef
xy|zz
30

SEEK

SEEK #n, position

Moves the file position, so the next read or write starts there. Position 1 is the first byte.

Μετακινεί τη θέση του αρχείου ώστε η επόμενη ανάγνωση ή εγγραφή να ξεκινά από εκεί. Η θέση 1 είναι το πρώτο byte.

open "k.txt" for output as #1
print #1, "abcdefgh";
close #1
open "k.txt" for input as #1
seek #1, 3
print input$(#1, 2)
close #1
de

WRITE #

WRITE #n, expression[, expression ...]

Writes values separated by commas, with strings in quotes. Freedom writes ", " (comma and space) between values.

Γράφει τιμές χωρισμένες με κόμμα, με τα κείμενα σε εισαγωγικά. Το Freedom γράφει ", " (κόμμα και κενό) ανάμεσα στις τιμές.

open "w.txt" for output as #1
write #1, "a", 5
close #1
open "w.txt" for input as #1
line input #1, x$
print x$
close #1
"a", 5
