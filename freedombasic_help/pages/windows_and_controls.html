BMPBUTTON

BMPBUTTON #w.name, "file.bmp", [branch], UL, x, y

A button that shows a bitmap picture instead of a caption.

Ένα κουμπί που δείχνει εικόνα bitmap αντί για κείμενο.

nomainwin
open "g" for graphics as #g
print #g, "fill red"
print #g, "getbmp a 0 0 20 20"
bmpsave "a", "b.bmp"
close #g
bmpbutton #w.b, "b.bmp", [c], UL, 10, 10
open "bb" for window as #w
print "ok"
close #w
end
[c]

BUTTON

BUTTON #w.name, "caption", [branch], UL, x, y, w, h

A push button. When it is clicked, the program jumps to [branch]. Send it "!disable", "!enable", "!show", "!hide" or a new caption string.

Ένα κουμπί. Όταν πατηθεί, το πρόγραμμα πηγαίνει στο [branch]. Στείλε του "!disable", "!enable", "!show", "!hide" ή νέο κείμενο.

nomainwin
button #w.b, "Hi", [clk], UL, 10, 10, 60, 25
open "b" for window as #w
print #w.b, "Bye"
print #w.b, "!disable"
print "ok"
close #w
end
[clk]
wait
ok

CHECKBOX

CHECKBOX #w.name, "caption", [setBranch], [resetBranch], x, y, w, h

print #w.c, "set"
print #w.c, "value? v$"
print v$
print #w.c, "reset"
print #w.c, "value? v$"
print v$
close #w
end

LISTBOX

LISTBOX #w.name, array$(, [branch], x, y, w, h

A list of choices taken from a string array (note the open parenthesis). Commands: "select text", "selectindex n", "selection? s$", "selectionindex? i", "count? n", "reload".

Μια λίστα επιλογών από πίνακα κειμένων (πρόσεξε την ανοιχτή παρένθεση). Εντολές: "select κείμενο", "selectindex n", "selection? s$", "selectionindex? i", "count? n", "reload".

a$(2) = "y"

print #w.l, "selection? s$"
print s$
print #w.l, "selectindex 3"
print #w.l, "selectionindex? i"
print i
print #w.l, "count? n"
print n

MENU

MENU #w, "title", "item", [branch], |, "item", [branch]

Adds a drop-down menu to a window. A | makes a separator line. Put & before a letter for the keyboard shortcut. Menu text may be written without quotes.

Προσθέτει αναδιπλούμενο μενού στο παράθυρο. Το | βάζει διαχωριστική γραμμή. Το & πριν από γράμμα ορίζει συντόμευση. Το κείμενο του μενού μπορεί να γραφτεί και χωρίς εισαγωγικά.

nomainwin
menu #w, "&File", "&Open", [o], |, "E&xit", [x]
open "m" for window as #w
print "menu"
close #w
end
[o]
wait
[x]
wait

OPEN ... FOR WINDOW

OPEN "title" FOR WINDOW AS #w

Opens a window. Set WindowWidth, WindowHeight, UpperLeftX and UpperLeftY before opening it. Controls declared before OPEN (BUTTON, TEXTBOX...) appear inside it. Commands go to the window with PRINT #w, "...".

Ανοίγει ένα παράθυρο. Όρισε τα WindowWidth, WindowHeight, UpperLeftX και UpperLeftY πριν το ανοίξεις. Τα controls που δηλώνονται πριν το OPEN (BUTTON, TEXTBOX...) εμφανίζονται μέσα του. Οι εντολές στέλνονται με PRINT #w, "...".

nomainwin
WindowWidth = 300
WindowHeight = 200
open "demo" for window as #w
print #w, "trapclose [q]"
print "open"
close #w
[q]

TEXTBOX

TEXTBOX #w.name, x, y, w, h

A one-line text entry. PRINT #w.t, "text" sets its contents; PRINT #w.t, "!contents? var$" reads it.

Ένα πεδίο κειμένου μίας γραμμής. Το PRINT #w.t, "κείμενο" ορίζει το περιεχόμενο· το PRINT #w.t, "!contents? var$" το διαβάζει.

nomainwin
textbox #w.t, 10, 10, 100, 25
open "t" for window as #w
print #w.t, "abc"
print #w.t, "!contents? c$"
print c$
close #w

TIMER

TIMER milliseconds, [branch] / TIMER 0

Jumps to [branch] every given number of milliseconds while the program waits. TIMER 0 stops it.

Πηγαίνει στο [branch] κάθε δοσμένα χιλιοστά του δευτερολέπτου όσο το πρόγραμμα περιμένει. Το TIMER 0 το σταματά.

nomainwin
open "t" for window as #w
timer 100, [tick]
wait
[tick]
timer 0
print "tick"
close #w
