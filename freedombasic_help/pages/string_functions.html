String functions

ASC

ASC(s$)

Returns the code of the first character of s$.

Επιστρέφει τον κωδικό του πρώτου χαρακτήρα του s$.

print asc("A")
65

CHR$

CHR$(n)

Returns the character whose code is n.

Επιστρέφει τον χαρακτήρα με κωδικό n.

print chr$(65); chr$(66)
AB

FORMAT$

FORMAT$(pattern$, x)

Formats a number with a pattern of # and a decimal point, like USING.

Μορφοποιεί έναν αριθμό με μοτίβο από # και υποδιαστολή, όπως το USING.

print format$("###.##", 3.14159)
3.14

INSTR

INSTR(s$, find$ [, start])

Returns the position of find$ inside s$, or 0 if it is not found. The first character is position 1.

Επιστρέφει τη θέση του find$ μέσα στο s$, ή 0 αν δεν βρεθεί. Ο πρώτος χαρακτήρας είναι η θέση 1.

print instr("freedom", "do")
print instr("freedom", "x")
5
0

INSTRREV

INSTRREV(s$, find$)

Position of the last find$ in s$ (0 if none). INSTR finds the first one.

Θέση του τελευταίου find$ στο s$ (0 αν δεν υπάρχει). Το INSTR βρίσκει το πρώτο.

print instrrev("abcabc", "b")
print instr("abcabc", "b")
5
2

LEFT$(s$, n)

print left$("freedom", 4)

LEN(s$)

LOWER$

LOWER$(s$)

MID$

MID$(s$, start [, length])

Returns part of s$ beginning at position start (the first character is position 1). Without length, it returns the rest of the string.

Επιστρέφει τμήμα του s$ που αρχίζει στη θέση start (ο πρώτος χαρακτήρας είναι η θέση 1). Χωρίς length, επιστρέφει το υπόλοιπο της συμβολοσειράς.

print mid$("freedom", 2, 3)
print mid$("freedom", 5)
ree
dom

PADLEFT$ / PADRIGHT$

PADLEFT$(s$, width, c$) / PADRIGHT$(s$, width, c$)

Pads a string with the character c$ on the left or on the right until it is width characters long.

Συμπληρώνει ένα κείμενο με τον χαρακτήρα c$ αριστερά ή δεξιά ώσπου να έχει μήκος width.

print padleft$("5", 3, "0")
print padright$("ab", 5, ".")
005
ab...

REMCHAR$

REMCHAR$(s$, c$)

Removes every occurrence of the character c$ from s$.

Αφαιρεί κάθε εμφάνιση του χαρακτήρα c$ από το s$.

print remchar$("a-b-c", "-")

REPEAT$(s$, n)

Repeats s$ n times.

REPLSTR$ / STR_REPLACE$

REPLSTR$(s$, find$, new$) / STR_REPLACE$(s$, find$, new$)

Replaces every find$ in s$ with new$.

Αντικαθιστά κάθε find$ στο s$ με new$.

STR$

STR$(n)

Converts a number to text.

Μετατρέπει έναν αριθμό σε κείμενο.

a$ = str$(42)
print a$ + "!"
42!

STRAFTER$ / STRBEFORE$ / STRBETWEEN$

STRAFTER$(s$, m$) / STRBEFORE$(s$, m$) / STRBETWEEN$(s$, a$, b$)

The text after the marker m$, before the marker m$, or between the markers a$ and b$.

Το κείμενο μετά τον δείκτη m$, πριν από τον δείκτη m$, ή ανάμεσα στους δείκτες a$ και b$.

print strafter$("key=value", "=")
print strbefore$("key=value", "=")
print strbetween$("a[b]c", "[", "]")

key
b

2

VAL

VAL(s$)

Converts text to a number. If the text does not start with a number, the result is 0.

Μετατρέπει κείμενο σε αριθμό. Αν το κείμενο δεν αρχίζει με αριθμό, το αποτέλεσμα είναι 0.

print val("12") + 1
print val("abc")
13
0

WORD$

WORD$(s$, n [, separator$])

Returns the n-th word of s$. Words are separated by spaces unless a separator is given.

Επιστρέφει την n-οστή λέξη του s$. Οι λέξεις χωρίζονται με κενά, εκτός αν δοθεί διαχωριστής.

print word$("one two three", 2)
print word$("a,b,c", 3, ",")
two
c
