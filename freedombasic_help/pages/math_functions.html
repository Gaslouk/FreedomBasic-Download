Math functions

ABS

ABS(n)

Returns the absolute value of n (without its sign).

Επιστρέφει την απόλυτη τιμή του n (χωρίς το πρόσημο).

print abs(-5)
5

INT

INT(n)

Removes the fractional part of n (it cuts toward zero: INT(7.9) is 7 and INT(-7.9) is -7).

Αφαιρεί το δεκαδικό μέρος του n (κόβει προς το μηδέν: το INT(7.9) είναι 7 και το INT(-7.9) είναι -7).

print int(7.9)
print int(-7.9)
7
-7

MOD

a MOD b

Returns the remainder of dividing a by b.

Επιστρέφει το υπόλοιπο της διαίρεσης του a με το b.

print 17 mod 5
2

RND

RND(1)

Returns a random number from 0 up to (but not including) 1. Multiply and use INT to get whole numbers in a range.

Επιστρέφει τυχαίο αριθμό από 0 έως (χωρίς να φτάνει το) 1. Πολλαπλασιάστε και χρησιμοποιήστε INT για ακέραιους σε εύρος.

r = int(rnd(1) * 6) + 1
if r >= 1 and r <= 6 then print "dice ok"
dice ok

SIN

SIN(angle)

Returns the sine of an angle given in radians.

Επιστρέφει το ημίτονο γωνίας σε ακτίνια.

print sin(0)
0

SQR

SQR(n)

Returns the square root of n.

Επιστρέφει την τετραγωνική ρίζα του n.

print sqr(81)
9
