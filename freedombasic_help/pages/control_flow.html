Control flow

CONTINUE

CONTINUE FOR | CONTINUE WHILE | CONTINUE DO

Skips the rest of the current pass of the loop and goes on with the next one. For FOR, the counter is still increased.

Παραλείπει το υπόλοιπο της τρέχουσας επανάληψης και συνεχίζει με την επόμενη. Στο FOR το μετρητής αυξάνεται κανονικά.

for i = 1 to 4
    if i = 2 then continue for
    print i;
next i
print
134

DO ... LOOP

DO [WHILE|UNTIL condition] ... LOOP [WHILE|UNTIL condition]

A general loop. The condition may be placed after DO (tested first) or after LOOP (the body runs at least once). EXIT DO leaves the loop.

Γενικός βρόχος. Η συνθήκη μπορεί να μπει μετά το DO (ελέγχεται πρώτη) ή μετά το LOOP (το σώμα εκτελείται τουλάχιστον μία φορά). Το EXIT DO βγάζει από τον βρόχο.

n = 0
do
    n = n + 1
loop until n >= 3
print n
3

EXIT SELECT

EXIT SELECT

Leaves the SELECT CASE block at once; the program continues after END SELECT.

Βγαίνει αμέσως από το μπλοκ SELECT CASE· το πρόγραμμα συνεχίζει μετά το END SELECT.

a = 1
select case a
    case 1
        print "in"
        if a = 1 then exit select
        print "never"
end select
print "after"

FOR ... NEXT

FOR variable = start TO end [STEP n] ... NEXT [variable]

Repeats the statements between FOR and NEXT while the variable counts from start to end. STEP sets the increment (it may be negative).

Επαναλαμβάνει τις εντολές ανάμεσα στο FOR και το NEXT, ενώ η μεταβλητή μετράει από την αρχή ως το τέλος. Το STEP ορίζει το βήμα (μπορεί να είναι αρνητικό).

for i = 1 to 3
    print i
next i
for j = 10 to 4 step -3
    print j
next j

GOSUB / RETURN

GOSUB label ... label ... RETURN

Jumps to a label, runs the statements there, and RETURN comes back to the line after the GOSUB. The label can be written as [name], as name: or as a line number - see LABELS.

Πηδά σε μια ετικέτα, εκτελεί τις εντολές εκεί, και το RETURN επιστρέφει στη γραμμή μετά το GOSUB. Η ετικέτα μπορεί να γραφτεί ως [όνομα], ως όνομα: ή ως αριθμός γραμμής - δες LABELS.

gosub [hello]
print "back"
end
[hello]
print "in subroutine"
return
in subroutine
back

GOTO

GOTO label

Continues execution at the label (see LABELS for the ways to write one). Unlike GOSUB, there is no automatic return.

Συνεχίζει την εκτέλεση στην ετικέτα (δες LABELS για τους τρόπους γραφής). Σε αντίθεση με το GOSUB, δεν υπάρχει αυτόματη επιστροφή.

goto [skip]
print "not printed"
[skip]
print "done"
done

IF

IF condition THEN statement [ELSE statement] | IF condition THEN ... [ELSE ...] END IF

Runs statements only when the condition is true. The one-line form takes a single statement after THEN; the block form ends with END IF and may contain ELSE.

Εκτελεί εντολές μόνο όταν η συνθήκη είναι αληθής. Η μορφή μίας γραμμής δέχεται μία εντολή μετά το THEN· η μορφή μπλοκ τελειώνει με END IF και μπορεί να έχει ELSE.

a = 7
if a > 5 then print "big" else print "small"
if a mod 2 = 0 then
    print "even"
else
    print "odd"
end if

odd

LABELS

[name] | name: | line number

A label marks a place in the program for GOTO, GOSUB and similar statements. Three forms were tested and all work: a name in square brackets, a name followed by a colon, and a line number at the start of a line. Names are not case sensitive, and a label written as name: can be called as steel or as [steel].

Η ετικέτα σημαδεύει μια θέση στο πρόγραμμα για τα GOTO, GOSUB και παρόμοιες εντολές. Δοκιμάστηκαν τρεις μορφές και δουλεύουν όλες: όνομα σε αγκύλες, όνομα με άνω-κάτω τελεία στο τέλος, και αριθμός γραμμής στην αρχή της γραμμής. Τα ονόματα δεν κάνουν διάκριση κεφαλαίων/μικρών, και ετικέτα που γράφεται name: μπορεί να κληθεί ως steel ή ως [steel].

gosub [one]
gosub two
gosub [three]
gosub 400
end
[one]
print "bracket label"
return
two:
print "colon label"
return
THREE:
print "colon label, upper case, called as [three]"
return
400 print "line-number label"
return

SELECT CASE

SELECT CASE expression ... CASE test[, test ...] ... CASE ELSE ... END SELECT

Chooses one block of statements by testing an expression against several cases. Each test can be a value (CASE 3), a range (CASE 1 TO 5), a comparison (CASE IS > 5; IS also accepts <, <=, >=, <>, =), or a comma-separated mix of these. Text values and text ranges (CASE "a" TO "f") work too, and the IS may be left out (CASE > 5). Only the first matching CASE runs; CASE ELSE runs when nothing matches, and if nothing matches and there is no CASE ELSE the program simply continues after END SELECT.

Επιλέγει ένα μπλοκ εντολών ελέγχοντας μια έκφραση με διάφορες περιπτώσεις. Κάθε έλεγχος μπορεί να είναι τιμή (CASE 3), εύρος (CASE 1 TO 5), σύγκριση (CASE IS > 5· το IS δέχεται και <, <=, >=, <>, =), ή μείγμα αυτών χωρισμένο με κόμματα. Δουλεύουν και κείμενα, ακόμη και εύρη κειμένου (CASE "a" TO "f"), και το IS μπορεί να παραλειφθεί (CASE > 5). Εκτελείται μόνο η πρώτη CASE που ταιριάζει· το CASE ELSE εκτελείται όταν δεν ταιριάζει καμία, και αν δεν ταιριάζει καμία και δεν υπάρχει CASE ELSE το πρόγραμμα συνεχίζει μετά το END SELECT.

for x = 1 to 16 step 5
    select case x
        case 1, 3, 5 to 9, is > 12
            print x; ": listed, range or above 12"
        case 2
            print x; ": two"
        case else
            print x; ": other"
    end select
next x
a$ = "b"
select case a$
    case "a"
        print "A"
    case "b", "c"
        print "B or C"
end select
c$ = "d"
select case c$
    case "a" to "f"
        print c$; " is in a to f"
    case > "f"
        print c$; " is after f"
end select

SUB (QB64 forms)

SUB name (p1 AS INTEGER, a() AS INTEGER) [STATIC] ... END SUB / name arg, arg / CALL name(arg, arg)

Besides the Liberty BASIC form (SUB name p1, p2 and CALL name p1, p2), Freedom accepts the QB64 form. The parameters may be in parentheses with types; a parameter declared with AS, or an array parameter such as a(), is passed by reference. The SUB can be called with CALL and a parenthesised argument list, or without CALL (name 1, 2 or name(1)). DECLARE SUB / DECLARE FUNCTION lines are accepted and ignored. A trailing STATIC is accepted, but variables do not keep their values between calls yet.

Εκτός από τη μορφή του Liberty BASIC (SUB name p1, p2 και CALL name p1, p2), το Freedom δέχεται και τη μορφή της QB64. Οι παράμετροι μπορεί να είναι σε παρενθέσεις με τύπους· μια παράμετρος με AS, ή παράμετρος πίνακα όπως a(), περνά by reference. Το SUB καλείται με CALL και λίστα ορισμάτων σε παρένθεση, ή χωρίς CALL (name 1, 2 ή name(1)). Οι γραμμές DECLARE SUB / DECLARE FUNCTION γίνονται δεκτές και αγνοούνται. Ένα STATIC στο τέλος γίνεται δεκτό, αλλά οι μεταβλητές δεν κρατούν ακόμα τιμές ανάμεσα στις κλήσεις.

declare sub fillit (a() as integer, k as integer)
dim v(3) as integer
call fillit(v(), 5)
print v(1)
show (v(1) + 1)
sub fillit (a() as integer, k as integer)
    a(1) = k
end sub
sub show (n)
    print "n = "; n
end sub
5
n = 6

WHILE ... WEND

WHILE condition ... WEND

Repeats the statements while the condition is true. The condition is tested before each pass, so the body may never run.

Επαναλαμβάνει τις εντολές όσο η συνθήκη είναι αληθής. Η συνθήκη ελέγχεται πριν από κάθε επανάληψη, οπότε το σώμα μπορεί να μην εκτελεστεί ποτέ.

n = 1
while n < 20
    n = n * 2
wend
print n
32
