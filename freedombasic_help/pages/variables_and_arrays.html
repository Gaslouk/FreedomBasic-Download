Variables and arrays

DATA / READ

DATA item, item, ... READ variable [, variable ...]

DATA stores values inside the program; READ takes them one by one, in order.

Το DATA αποθηκεύει τιμές μέσα στο πρόγραμμα· το READ τις παίρνει μία-μία, με τη σειρά.

data 3, "pear", 7
read a, f$, b
print a; " "; f$; " "; b
3 pear 7

DIM

DIM name(size) [, name2(rows, cols) ...]

Declares an array. Indexes start at 0, so DIM a(5) has elements 0 to 5. A name ending in $ holds text.

Δηλώνει πίνακα. Οι δείκτες ξεκινούν από το 0, άρα το DIM a(5) έχει στοιχεία 0 έως 5. Όνομα που τελειώνει σε $ περιέχει κείμενο.

dim a(3)
a(0) = 10 : a(3) = 40
print a(0); " "; a(3)
dim m$(1, 1)
m$(1, 1) = "x"
print m$(1, 1)
10 40
x

REDIM

REDIM name(newsize)

Changes the size of an array that was declared with DIM. The old contents are cleared.

Αλλάζει το μέγεθος πίνακα που δηλώθηκε με DIM. Τα παλιά περιεχόμενα καθαρίζουν.

dim a(2)
a(1) = 5
redim a(4)
print a(1)
0
