BYREF

SUB name BYREF x

Passes a variable so that the SUB can change the caller's copy.

Περνά μια μεταβλητή ώστε το SUB να αλλάζει το αντίγραφο του καλούντος.

a = 1
call s a
print a
sub s byref x
    x = 9
end sub
9

EXIT

EXIT FOR / EXIT WHILE / EXIT DO / EXIT SUB / EXIT FUNCTION

Leaves the loop, SUB or FUNCTION at once.

Βγαίνει αμέσως από τον βρόχο, το SUB ή τη FUNCTION.

for i = 1 to 5
    if i = 3 then exit for
next i
print i

GLOBAL / SHARED / STATIC

GLOBAL a / SHARED a / STATIC a

GLOBAL makes a variable visible inside every SUB and FUNCTION. SHARED shares a named variable with one SUB. STATIC keeps a variable value between calls.

Το GLOBAL κάνει μια μεταβλητή ορατή μέσα σε κάθε SUB και FUNCTION. Το SHARED μοιράζει μεταβλητή με ένα SUB. Το STATIC κρατά την τιμή μεταξύ κλήσεων.

global g
g = 5
call s
print g
sub s
    static n
    n = n + 1
    g = g + n
end sub
6

INKEY$

Returns the key waiting in the keyboard buffer, or an empty string if none.

Επιστρέφει το πλήκτρο που περιμένει στο buffer πληκτρολογίου ή κενό αν δεν υπάρχει.

a$ = inkey$
print len(a$)
0

ON ERROR / ERR / ERR$

ON ERROR GOTO [label]

Στέλνει ένα σφάλμα εκτέλεσης στο [label] αντί να σταματήσει. Το ERR είναι ο αριθμός και το ERR$ το κείμενο.

on error goto [e]
x = 1 / 0
print "not reached"
end
[e]
print err
print err$

RANDOMIZE

RANDOMIZE seed

Starts the random generator from a seed. The same seed gives the same sequence.

Ξεκινά τη γεννήτρια τυχαίων από ένα seed. Το ίδιο seed δίνει την ίδια ακολουθία.

print r >= 0 and r < 1

TICKS / TIME$ / DATE$

TICKS() / TIME$() / DATE$()

TICKS() returns milliseconds since the program started, TIME$() the clock time, DATE$() the date. TIME$("seconds") and DATE$("days") return numbers.

Το TICKS() επιστρέφει χιλιοστά του δευτερολέπτου από την εκκίνηση, το TIME$() την ώρα, το DATE$() την ημερομηνία. Τα TIME$("seconds") και DATE$("days") επιστρέφουν αριθμούς.

print len(time$()) > 0
print len(date$()) > 0
print ticks() >= 0
1
