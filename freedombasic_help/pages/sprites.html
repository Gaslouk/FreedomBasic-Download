Sprites

ADDSPRITE

PRINT #g, "addsprite name bmpname"

Creates a sprite called name from a loaded image.

Δημιουργεί sprite με όνομα name από μια φορτωμένη εικόνα.

nomainwin
open "g" for graphics as #g
print #g, "fill white"
print #g, "getbmp a 0 0 8 8"
bmpsave "a", "sp.bmp"
loadbmp "q", "sp.bmp"
print #g, "addsprite s q"
print #g, "spritexy s 10 20"
print "drawn"
drawn

SPRITEXY / SPRITEXY?

PRINT #g, "spritexy name x y" / "spritexy? name x y"

spritexy puts the sprite at x y. spritexy? reads its position into the variables x and y.

Το spritexy βάζει το sprite στο x y. Το spritexy? διαβάζει τη θέση του στις μεταβλητές x και y.

nomainwin
open "g" for graphics as #g
print #g, "fill white"
print #g, "getbmp a 0 0 8 8"
bmpsave "a", "sp.bmp"
loadbmp "q", "sp.bmp"
print #g, "addsprite s q"
print #g, "spritexy s 10 20"
print #g, "spritexy? s x y"
print x; " "; y
print "drawn"
10 20
drawn
