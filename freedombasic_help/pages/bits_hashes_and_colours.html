READBIT / SETBIT / RESETBIT / TOGGLEBIT

READBIT(n, bit) / SETBIT(n, bit) / RESETBIT(n, bit) / TOGGLEBIT(n, bit)

Work on one bit of n; bit 0 is the lowest. SETBIT turns it on, RESETBIT turns it off, TOGGLEBIT flips it, READBIT tests it and gives -1 when the bit is on and 0 when it is off.

Δουλεύουν σε ένα bit του n· το bit 0 είναι το χαμηλότερο. Το SETBIT το ανάβει, το RESETBIT το σβήνει, το TOGGLEBIT το αντιστρέφει, το READBIT το ελέγχει και δίνει -1 όταν είναι αναμμένο και 0 όταν είναι σβηστό.

print setbit(0, 3)
print resetbit(15, 0)
print togglebit(5, 1)
print readbit(5, 0)
print readbit(5, 1)
8
14

-1
0

RED / GREEN / BLUE / ALPHA

RED(c) / GREEN(c) / BLUE(c) / ALPHA(c)

Extract one component from a packed colour made with _RGB or _RGBA.

Εξάγουν ένα συστατικό από πακεταρισμένο χρώμα που έγινε με _RGB ή _RGBA.

c = _rgba(1, 2, 3, 4)
print red(c); green(c); blue(c); alpha(c)
1234

SHL / SHR / ROL / ROR

SHL(n, k) / SHR(n, k) / ROL(n, k) / ROR(n, k)

Shift the bits of n left or right by k places, or rotate them. (The QB64 names _SHL, _SHR, _ROL and _ROR work too.)

Ολισθαίνουν τα bits του n αριστερά ή δεξιά κατά k θέσεις, ή τα περιστρέφουν. (Δουλεύουν και τα ονόματα της QB64 _SHL, _SHR, _ROL και _ROR.)

print shl(1, 3)
print shr(8, 2)
print rol(1, 1)
print ror(2, 1)
8
2
2
1

URLENCODE$ / URLDECODE$

URLENCODE$(s$) / URLDECODE$(s$)

Convert text for use inside a web address (a space becomes %20) and back.

Μετατρέπουν κείμενο για χρήση σε διεύθυνση ιστού (το κενό γίνεται %20) και αντίστροφα.

print urlencode$("a b&c")
print urldecode$("a%20b")
a%20b%26c
a b
