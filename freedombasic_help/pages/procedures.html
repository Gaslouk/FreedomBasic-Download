FUNCTION / END FUNCTION

FUNCTION name(param1, param2) ... name = value ... END FUNCTION

Defines a function that returns a value. Assign the result to the function's own name before END FUNCTION. Call it inside an expression.

Ορίζει συνάρτηση που επιστρέφει τιμή. Αναθέστε το αποτέλεσμα στο όνομα της ίδιας της συνάρτησης πριν το END FUNCTION. Καλείται μέσα σε έκφραση.

print square(6)
end
function square(n)
    square = n * n
end function

SUB / END SUB / CALL

SUB name param1, param2 ... END SUB | CALL name arg1, arg2

Defines a subroutine with its own local variables and calls it with CALL. Parameters are passed by value unless declared BYREF.

Ορίζει υπορουτίνα με δικές της τοπικές μεταβλητές και την καλεί με CALL. Οι παράμετροι περνούν κατά τιμή εκτός αν δηλωθούν BYREF.

call greet "Ann"
end
sub greet who$
    print "Hello, "; who$
end sub
