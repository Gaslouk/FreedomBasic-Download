Basic statements

INPUT

INPUT ["prompt";] variable [, variable ...]

Asks the user to type a value and stores it in the variable. A variable name ending in $ receives text; without $ it receives a number.

Ζητά από τον χρήστη να πληκτρολογήσει μια τιμή και την αποθηκεύει στη μεταβλητή. Όνομα που τελειώνει σε $ παίρνει κείμενο· χωρίς $ παίρνει αριθμό.

input "Your name? "; n$
print "Hello, "; n$

Not run in the automatic check: waits for keyboard input

PRINT

PRINT expression [; expression ...]

Writes values to the main window (or to an open file or window, with PRINT #handle, ...). A semicolon between items joins them with no space. Without a trailing semicolon, the output moves to a new line.

Γράφει τιμές στο κύριο παράθυρο (ή σε ανοιχτό αρχείο ή παράθυρο, με PRINT #handle, ...). Το ερωτηματικό ανάμεσα στα στοιχεία τα ενώνει χωρίς κενό. Χωρίς ερωτηματικό στο τέλος, η έξοδος πάει σε νέα γραμμή.

print "Total: "; 2 + 3
print "a"; "b"; "c"
print
