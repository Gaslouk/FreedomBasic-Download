Graphics

box / boxfilled

PRINT #g, "box x y" / "boxfilled x y"

Draws a rectangle from the current position to x y. box draws only the outline in the pen colour. boxfilled also fills it with the backcolor.

Σχεδιάζει ορθογώνιο από την τρέχουσα θέση ως το x y. Το box σχεδιάζει μόνο το περίγραμμα με το χρώμα του στυλό. Το boxfilled το γεμίζει επιπλέον με το backcolor.

nomainwin
open "g" for graphics as #g
print #g, "color red"
print #g, "backcolor yellow"
print #g, "place 10 10"
print #g, "boxfilled 80 60"
print "drawn"
drawn

color / backcolor

PRINT #g, "color name|r g b" / "backcolor name|r g b"

color sets the pen colour (lines and outlines), backcolor sets the fill colour used by the filled shapes. A colour is a name (red, green, blue, yellow, cyan, pink, brown, black, white, darkred, lightgray, palegray...) or three numbers 0-255.

Το color ορίζει το χρώμα του στυλό (γραμμές και περιγράμματα), το backcolor το χρώμα γεμίσματος των γεμάτων σχημάτων. Το χρώμα είναι όνομα (red, green, blue, yellow, cyan, pink, brown, black, white, darkred, lightgray, palegray...) ή τρεις αριθμοί 0-255.

nomainwin
open "g" for graphics as #g
print #g, "color red"
print #g, "backcolor 0 255 0"
print #g, "place 10 10"
print #g, "boxfilled 60 60"
print "drawn"

flush / redraw / cls / discard

PRINT #g, "flush" / "redraw" / "cls" / "discard"

flush makes the drawing permanent in the window. cls clears the window. discard throws away the drawing segments created so far.

Το flush κάνει το σχέδιο μόνιμο στο παράθυρο. Το cls καθαρίζει το παράθυρο. Το discard πετάει τα τμήματα σχεδίου που έχουν δημιουργηθεί.

nomainwin
open "g" for graphics as #g
print #g, "fill red"
print #g, "flush"
print #g, "cls"
print "drawn"

getbmp / drawbmp

PRINT #g, "getbmp name x y w h" / "drawbmp name x y"

getbmp copies an area of the window into an image called name. drawbmp draws a stored image at x y.

Το getbmp αντιγράφει μια περιοχή του παραθύρου σε εικόνα με το όνομα name. Το drawbmp σχεδιάζει μια αποθηκευμένη εικόνα στο x y.

place / goto / line

PRINT #g, "place x y" / "goto x y" / "line x y"

place moves the pen without drawing. goto draws a line from the current position to x y when the pen is down. line x y draws from the current position to x y. The pen must be down (command down).

Το place μετακινεί το στυλό χωρίς σχέδιο. Το goto σχεδιάζει γραμμή από την τρέχουσα θέση στο x y όταν το στυλό είναι κάτω. Το line x y σχεδιάζει από την τρέχουσα θέση στο x y. Το στυλό πρέπει να είναι κάτω (εντολή down).

nomainwin
open "g" for graphics as #g
print #g, "down"
print #g, "color black"
print #g, "place 10 10"
print #g, "goto 90 10"
print #g, "line 90 90"
print "drawn"
drawn

Text in graphics

A string that starts with a backslash is drawn as text at the current position. font sets the typeface and size first.

trapclose

PRINT #g, "trapclose [label]"

Runs the code at [label] when the user closes the window, instead of closing it at once.

Εκτελεί τον κώδικα στο [label] όταν ο χρήστης κλείσει το παράθυρο, αντί να κλείσει αμέσως.

nomainwin
open "g" for graphics as #g
print #g, "trapclose [bye]"
goto [skip]
[bye]
close #g
end
[skip]

when

PRINT #g, "when event [label]"

Calls a branch label when an event happens: leftButtonDown, leftButtonUp, rightButtonDown, mouseMove, characterInput. Use WAIT to keep the program alive.

Καλεί μια ετικέτα όταν συμβεί ένα γεγονός: leftButtonDown, leftButtonUp, rightButtonDown, mouseMove, characterInput. Χρησιμοποίησε WAIT για να μείνει ζωντανό το πρόγραμμα.

nomainwin
open "g" for graphics as #g
print #g, "when leftButtonDown [click]"
goto [skip]
[click]
wait
[skip]
print "drawn"
